sitegen is a faster drop-in for makefun-site 1.0.0: it builds a static site from the same input and returns byte-identical output, about 2.5x faster than the house baseline on build work. It reimplements the build pipeline with a fused Markdown renderer and templates compiled once to JavaScript functions.

## Run it

```sh
node main.ts
```
